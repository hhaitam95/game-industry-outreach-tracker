# Studio Outreach

A small personal tool for finding game studios that accept speculative applications and tracking the applications you send yourself.

## How it works

1. Start with broad public directories of game studios.
2. Check each studio's own website or studio-controlled application system.
3. Keep it in this list only when the official page explicitly accepts speculative, unsolicited, open or general applications without a specific advertised vacancy.
4. Open the application page, apply yourself, and save it in the private tracker.

A generic careers page, an advertised vacancy or an aggregator claim is not enough. Studios without a qualifying route are simply left out.

Studios whose games or ordinary work involve pornography, adult-only games, erotic or sexually explicit content must be excluded, even when they otherwise have a qualifying open-application route. Also exclude routes that ask applicants to confirm comfort with that content. If a studio's content suitability is unclear, leave it out pending manual review. This is a sexual-content suitability rule, not a blanket exclusion of mature-rated games generally.

## Website

The site shows only studios that passed the official-page check. Each entry includes the studio, country, application link, short conditions note and date checked. Search by studio, country or discipline.

The tracker is encrypted in your browser. Personal application records stay local; the app does not send emails or submit applications.

## Research sources

Public studio directories such as GameDevMap and Hitmarker are candidate sources only. Their entries are not copied into the published directory and do not prove that a studio accepts speculative applications. MobyGames can help identify credited developers and publishers, but it is a game-credit database rather than a direct speculative-application directory.

## Later

Once the list is useful, a small scheduled check can revisit saved pages and flag links that disappear or change. A separate search can find newly published open-application pages. Unclear cases should remain for manual review.

## Run locally

Use Node.js 24 and npm:

```sh
npm ci
npm run dev
```
