# Handoff

This is a small personal tool to find studios with official speculative/open-application routes and track applications sent manually.

The public list is `src/data/speculative-route-directory.json`. It contains only studios with official application routes. Personal tracker records stay encrypted in the browser.

Use public studio directories as leads only. Verify each route on the studio's own page. Exclude studios materially focused on pornography/erotica/sexually explicit entertainment, gambling/betting/casinos (including simulated/social-casino games), recreational drugs/cannabis, alcohol, tobacco/nicotine/vaping, and closely related adult or vice industries. Apply this to the studio's business/portfolio and to the actual project or role. Exclude routes that ask applicants to confirm comfort with such content. Leave unclear cases out pending manual review. Do not exclude mainstream studios solely for incidental fictional references in an otherwise general-audience game. Do not add job-board features, resume tools, outreach automation or complex workflows.

Future automation should only recheck saved links and discover new official speculative-application pages.
