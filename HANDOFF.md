# Handoff

This is a small personal tool to find studios with official speculative/open-application routes and track applications sent manually.

The public list is `src/data/speculative-route-directory.json`. It contains only studios with official application routes. Personal tracker records stay encrypted in the browser.

Use public studio directories as leads only. Verify each route on the studio's own page. Do not add job-board features, resume tools, outreach automation or complex workflows.

Future automation should only recheck saved links and discover new official speculative-application pages.
