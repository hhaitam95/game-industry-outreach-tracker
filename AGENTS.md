# Project notes

Keep StudioScout useful and lightweight.

- Include only studios with a directly verified speculative/open/general application route.
- Use broad public studio directories as candidate sources, never as proof of an application route.
- Exclude studios materially focused on pornography, erotica, explicit sexual entertainment, gambling/betting/casinos (including simulated/social casino), recreational drugs/cannabis, alcohol, tobacco/nicotine/vaping or related adult/vice sectors. Apply this to studio portfolio/core business and the specific project or role.
- Leave unclear content-suitability cases out pending review. Do not exclude mainstream games solely for incidental fictional references to mature themes.
- Do not publish guessed headquarters, branches, employee counts, ownership or game credits. Use “Not disclosed” or “Not researched”.
- Keep HQ separate from the location/eligibility stated on an application route. HQ is a fallback reference, not evidence a job is based there.
- Add a source link and reference date for researched company facts; mark scale as an editorial indication.
- Keep the tracker local in browser localStorage. No account, login, encryption, backend, remote sync, email or automatic applications.
- Never commit personal application records.
- Do not add job boards, resume tools, outreach generators, analytics, crawlers or scheduled discovery.
- Prefer small direct changes.
