# First application campaign runbook

**Purpose:** Use the current Game Industry Outreach Tracker for a manually reviewed application campaign.  
**Current workflow:** Studio Discovery → Candidate Profile → Matching → Application Preparation → manual employer-site submission → Application Tracker.  
**Important:** Application Preparation V1 is a private, user-assisted checklist and notes workspace. It does not automatically inspect or fill third-party ATS forms.

## 1. Before opening the first match

1. Open the live GitHub Pages site after the latest successful deployment.
2. Go to **My profile**.
3. Complete contact details, professional summary, employment, education, projects/training and skills.
4. For each skill, select the correct evidence level and connect it to actual work, education, training or a project. Do not promote learning/exposure into demonstrated experience.
5. Add your approved master resume/CV, motivation letter and portfolio link. Check that the correct original documents are attached.
6. Set role-family, studio-type, work-model and geographic preferences.
7. Export a Candidate Profile backup and store it privately.

Do not put personal details, CVs, motivation drafts or your shortlist in repository files, GitHub issues or public branches.

## 2. Review and select studios

1. Open **Matches** after the profile is complete.
2. Review the professional relevance, application-route status/readiness and personal priority separately.
3. Open each studio's official website and speculative/open application evidence. The directory entry is a research snapshot, not a live vacancy guarantee.
4. Check the current route, discipline/department scope, work model, language, actual hiring location and applicant eligibility. Headquarters alone does not establish those facts.
5. Save a target to **My applications** only when you genuinely intend to consider applying.
6. Keep promising but uncertain targets visible for manual review rather than assuming unknown facts are negative.

## 3. Prepare each application

From **My applications**, open the **Prepare** panel for the saved studio.

1. Re-open the official application route and mark **Official application route rechecked** only after checking it.
2. Review the employer's requirements, questions, document list, language and location/eligibility instructions.
3. Paste or summarize those facts in **Employer requirements & application questions**. Include the official source URL or note where it was found.
4. Mark the resume/CV, motivation letter and portfolio checks only when the actual files/links are ready for that application.
5. Draft form responses in **Draft answers & missing information**. Keep every factual claim grounded in the Candidate Profile. Mark questions needing your input rather than guessing.
6. Review all answers and documents. The checklist is a preparation aid, not proof that the external form accepts them.

The preparation panel is saved automatically in this browser and included in tracker backup export/restore. It is not sent to a server.

## 4. Submit manually and track the outcome

1. Open the official employer application link from the tracker.
2. Complete the live form or email externally. Verify every field, attached file, declaration and destination address.
3. Perform the final review and click Submit/Send yourself.
4. Return to **My applications** and change the record to **Applied**. Confirm the dialog only after the submission has actually succeeded.
5. Record the submitted date, role/discipline, material version, confirmation/receipt and any useful details in private notes.
6. When the employer responds, update the record to Interview, Offer or Archived as applicable. The tracker asks for submission confirmation before recording Interview/Offer if no submitted date exists.
7. Keep communication in your email account. Record important updates manually in the tracker.

A saved or prepared target is not a submitted application. Only the user-confirmed Applied stage counts as an application submission.

## 5. Backups and browser storage

- Export the Candidate Profile backup before a major application session and whenever profile documents/materials change.
- Export the My applications backup after saving targets, preparing answers or changing statuses/notes.
- Keep both backup files private. They can contain contact information, original documents, draft answers and application history.
- The current website stores profile and tracker information in this browser. It does not sync across devices and browser storage is not automatically encrypted; browser/site data can be cleared.
- Do not use the same backup file to roll back newer edits without reviewing the replacement confirmation. If the tracker changes while a backup is being read, the stale import is cancelled to preserve the newer edits.

## 6. What the tool does not automate yet

- It does not sign in to SmartRecruiters, Greenhouse, Workday, Lever or other ATS accounts.
- It does not automatically read every dynamic or authenticated application form.
- It does not auto-fill fields or upload files to external sites.
- It does not read or send email.
- It never clicks the final Apply/Submit button on your behalf.

The preparation notes and checklist make the manual application process more organized while these integrations remain unimplemented and separately gated.
