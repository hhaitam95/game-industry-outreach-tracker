# Resume Guidance Sources

**Reviewed:** 2026-10-24  
These sources inform the synthesized rules in this folder. The repository must store short summaries and its own guidance—not copy complete articles or proprietary content. Revisit links periodically and record meaningful changes. For the Phase 6a document adapters, the pinned package metadata was reviewed on 2026-10-28.

| Source | URL | Relevant guidance | Scope/caveat |
|---|---|---|---|
| University of Pennsylvania Career Services — Resume | https://careerservices.upenn.edu/channels/resume/ | Readable 10–12 pt typography, simple consistent layout, whitespace, caution about graphics/text boxes and ATS parsing, tailoring to a role. | General career guidance; its page-length advice depends on audience. Do not universalize undergraduate recommendations to experienced candidates. |
| Penn State Engineering — Résumés | https://career.engr.psu.edu/students/basics/resume.aspx | Clear fonts, conventional headings, warning that tables/graphics/text boxes can confuse some ATS tools, honest use of job-description terms. | Engineering career guidance, not a guarantee about every ATS. |
| Epic Games — Career Paths / General Resume Tips | https://www.epicgames.com/site/earlycareers/career-paths | Clear focus, uncluttered resume, relevant information easy to scan; portfolio links should be easy to find where applicable; one page is common but not a hard rule and resumes rarely need more than two pages. | Early-career guidance; adapt to role, experience and each studio's application instructions. |
| Mozilla PDF.js | https://mozilla.github.io/pdf.js/ | Browser-side text-layer extraction from locally selected PDF files, using a locally bundled worker asset. | Engineering reference, not resume advice. OCR remains out of scope. Phase 6a pins pdfjs-dist 6.4.299, Apache-2.0. |
| Mammoth.js | https://github.com/mwilliamson/mammoth.js | Browser `extractRawText({arrayBuffer})` API returns plain DOCX text and parser messages. | Engineering reference, not resume advice. This workflow never renders converted HTML. Phase 6a pins Mammoth 1.13.0, BSD-2-Clause. |
| GitHub Pages documentation | https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages | Static hosting constraints relevant to browser-side processing and deployment. | Hosting reference, not resume advice. |

## Maintenance policy

- This is a starting reference set, not an assertion of universal or legally binding standards.
- Store review date, summary and applicability for each source.
- If an external source becomes unavailable, record the last successful review rather than inventing new guidance.
- Apply employer instructions before generalized advice.
