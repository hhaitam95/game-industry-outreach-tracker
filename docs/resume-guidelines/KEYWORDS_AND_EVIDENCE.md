# Keywords, Grammar, Tone, and Evidence

**Last reviewed:** 2026-10-24

## Job-description keywords

- Extract required skills, preferred skills, responsibilities, tools and repeated terms from the selected role.
- Map each term to evidence in the profile/CV: supported, partial/transferable, not evidenced, or unclear.
- Use accurate keywords in context. Do not add a skill because it appears frequently in the job description.
- Avoid hidden text, keyword stuffing, awkward repetition and claims designed only to manipulate ATS ranking.
- When no exact experience exists, state the transferable concept accurately or mark a gap.

## Grammar and tone checks

- Check spelling, punctuation, sentence clarity, tense consistency, parallel bullet structure, dates, capitalization, acronyms and terminology.
- Prefer active, specific language and concise sentences.
- Flag repetitive openers, vague claims, excessive adjectives and unsubstantiated superlatives.
- Keep the tone professional and confident, not exaggerated or apologetic.
- Check the actual document render and extracted text, not just the structured source data.

## Evidence and factuality

- Every proposed skill, achievement, tool, metric, role, degree, certification and game credit should trace to an approved profile/CV fact or user-confirmed addition.
- If a claim is plausible but not evidenced, ask the user or leave it out.
- Track generated edits so the user can compare before and after.
- Do not treat model-generated text as factual evidence.
- Always provide the user with a final review before download or application.
